# 🚛 FleetFlow

### Modular Fleet & Logistics Management System

Built for **Odoo x Gujarat Vidyapith Hackathon**

---

## 📌 Project Overview

FleetFlow is a secure, centralized fleet and logistics management platform designed to replace manual logbooks with a digital, real-time operational system.

The platform enables organizations to efficiently manage:

* Vehicles and asset lifecycle
* Driver compliance and safety
* Trip dispatch and logistics workflows
* Maintenance scheduling and service tracking
* Fuel consumption and operational expenses
* Financial analytics and performance reporting

FleetFlow is designed with a **security-first architecture** and **role-based access control**, ensuring safe and controlled access to operational data.

---

## 🎯 Problem Statement

Manual fleet tracking systems lead to:

* Poor asset utilization
* Lack of maintenance visibility
* Safety compliance risks
* Uncontrolled operational costs
* Data fragmentation

FleetFlow solves these challenges through structured workflows, automation, and real-time monitoring.

## ⚙ Installation Guide

1. Clone repository

```
git clone <repository-url>
```

2. Import database schema into MySQL

3. Configure database credentials in:

```
/config/database.php
```

4. Run project on local server (Apache / XAMPP / Nginx)

5. Access application via browser
